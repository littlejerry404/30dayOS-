# 30dayOS —— 《30天自制操作系统》配套光盘内容（中文汉化版）

本仓库是日本程序员 **川合秀实（H.Kawai）** 所著《30日でできる！OS自作入門》（中译《30天自制操作系统》）一书配套光盘内容的**中文汉化版**，用于学习如何从零开始编写一个小型操作系统（haribote OS）。

> ⚠️ **声明**：本仓库为非官方存档，仅供学习交流。原始代码著作权归原作者川合秀实所有。

## 这是什么

《30天自制操作系统》通过 30 天循序渐进的方式，从开机引导扇区开始，带你逐步实现一个具备内存管理、中断、定时器、窗口系统、命令行等功能的操作系统。本仓库包含书中所有章节的源代码、开发工具以及最终的可运行映像。

## 目录结构

```
.
├── projects/       # 30 天逐日源码（01_day ~ 30_day）
│   ├── 01_day/     # helloos0 ~ helloos2：引导扇区
│   ├── 02_day/     # helloos3 ~ helloos5：进一步学习
│   ├── 03_day/     # harib00a ...：进入操作系统本体开发
│   └── ...
├── tolset/         # 开发工具集（z_tools：nask 汇编器、GCC、QEMU 等）
├── omake/          # 附加资料（OSASK、工具源码等）
├── haribote.img    # 最终生成的软盘映像
└── readme.txt      # 原书正文定稿后的补充注意事项
```

## 如何使用

以 Windows 为例：

1. 进入某一天的工程目录，例如：
   ```
   projects/30_day/harib27f/
   ```
2. 双击 `!cons_nt.bat`（Windows 2000/XP 及以上）或 `!cons_9x.bat`（Windows 9x），
   会打开一个已配置好工具链环境的命令行窗口
3. 在该命令行中执行：
   ```
   make          # 编译
   make run      # 用 QEMU 运行（或直接运行 run.bat）
   ```

> 如果工具报「只读属性」错误，请先参考 `readme.txt` 去掉文件的只读属性。
